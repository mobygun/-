티에스코어 업무 기록 앱 - 설치 파일
====================================
아래 파일 9개를 한 곳에 올려야 앱이 됩니다. 이름은 절대 바꾸지 마세요.

  index.html      앱 화면
  template.js     경비 지출대장 엑셀 원본 서식
  xlsxbuild.js    경비 엑셀 생성 기능
  template2.js    차량 운행기록부 엑셀 원본 서식
  drivebuild.js   운행기록부 엑셀 생성 기능
  sw.js           인터넷 없이도 열리게 해주는 파일
  manifest.json   앱 이름/아이콘 설정
  icon-192.png    앱 아이콘
  icon-512.png    앱 아이콘
