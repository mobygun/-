현장 경비 지출대장 - 앱 설치 파일
==================================
이 폴더의 파일 6개를 한 곳에 올려야 앱이 됩니다.
파일 이름은 절대 바꾸지 마세요.

  index.html      앱 화면
  template.js     회사 엑셀 원본 서식 (이게 있어야 원본 그대로 나옵니다)
  xlsxbuild.js    엑셀 만드는 기능
  sw.js           인터넷 없이도 열리게 해주는 파일
  icon-192.png    앱 아이콘
  icon-512.png    앱 아이콘

설치 방법은 대화창의 안내를 참고하세요.
