현장 경비 지출대장 앱 - 설치 파일
=================================

이 폴더 안의 파일 5개를 GitHub(깃허브)에 올리면 앱이 됩니다.

  index.html      앱 화면 (본체)
  manifest.json   앱 이름/아이콘 설정
  sw.js           인터넷 없이도 열리게 해주는 파일
  icon-192.png    앱 아이콘 (작은)
  icon-512.png    앱 아이콘 (큰)

주의: 파일 이름을 절대 바꾸지 마세요. 5개를 모두 같은 위치에 올려야 합니다.
자세한 설치 방법은 대화창의 8단계 안내를 참고하세요.
